#  BookVault

BookVault is a web application that helps users discover books using the Open Library API. Users can search for books by title or subject, filter by category, sort by publication year, and view more details about each book.

---

## Features

- Search books by title or keyword
- Filter books by category
- Sort books by newest or oldest publication year
- Display book covers, authors, and publication years
- View additional book information
- Error handling for invalid searches
- Responsive and user-friendly interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open Library API

---

## API Used

Open Library Search API

https://openlibrary.org/developers/api

Book cover images are provided using the Open Library Covers API.

---

## Running Locally

1. Download or clone this repository.

2. Open the project in Visual Studio Code.

3. Install the Live Server extension.

4. Right-click `index.html`.

5. Click **Open with Live Server**.

## Challenges

During development, the original Google Books API exceeded its daily quota. To resolve this issue, the project was migrated to the Open Library API, which provides reliable access to book information without requiring an API key.
